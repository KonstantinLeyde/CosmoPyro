Citation
========

If you use **CosmoPyro** in your research, please cite:

   K. Leyde and E. Colangeli, *CosmoPyro: Gradients for Gravitational-Wave
   Cosmology*, `arXiv:2608.18281 <https://arxiv.org/abs/2608.18281>`_ (2026).

.. code-block:: bibtex

   @article{Leyde:2026bat,
       author = "Leyde, Konstantin and Colangeli, Elena",
       title = "{CosmoPyro: Gradients for Gravitational-Wave Cosmology}",
       eprint = "2608.18281",
       archivePrefix = "arXiv",
       primaryClass = "astro-ph.CO",
       month = "8",
       year = "2026"
   }

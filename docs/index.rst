CosmoPyro
=========

**CosmoPyro** is a JAX/NumPyro framework for gravitational-wave cosmology.
It performs hierarchical Bayesian inference on compact-binary populations,
jointly constraining cosmological parameters (e.g. :math:`H_0`), the
source-frame mass distribution, and the merger rate evolution.
